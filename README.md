# 가계부 (Galaxy S22+용 PWA)

설치형 웹앱(PWA)으로 만든 개인 가계부입니다. 홈 화면에 설치하면 일반 앱처럼 전체 화면으로 열리고, 인터넷 없이도 동작합니다.
**데이터는 휴대폰 안(브라우저 저장소)에만 저장되며 어디로도 전송되지 않습니다.**

## 기능
- **내역**: 지출/수입 기록 (금액·카테고리·날짜·결제수단·메모), 날짜별 묶음, 전체/지출/수입 필터, 전체 기간 검색
- **월 예산**: 사용률 막대, 남은 금액, "남은 n일 동안 하루 얼마" 안내, 카테고리별 예산과 초과 경고
- **달력**: 날짜별 수입/지출 합계, 날짜를 누르면 그날 내역과 바로 추가
- **통계**: 최근 6개월 추이, 전월 대비 증감, 카테고리별 비중(누르면 해당 내역)
- **매월 반복**: 월세·통신비·급여 등을 매달 같은 날 자동 기록 (31일 설정 시 짧은 달은 말일)
- **관리**: 카테고리(이모지 아이콘)·결제수단 추가/편집/순서 변경, 통화(SGD/KRW/USD/EUR/JPY), 라이트/다크 테마
- **백업**: JSON 백업을 Google Drive·메일 등으로 공유 또는 파일 저장, 복원, CSV(엑셀) 내보내기
- 좌우 스와이프로 월 이동, 뒤로가기 제스처로 창 닫기, 앱 아이콘 길게 눌러 "지출 기록" 바로가기

## 폰에 설치하기 (GitHub Pages, 무료)
PWA를 설치하려면 HTTPS 주소가 필요해서, 이 폴더를 GitHub 저장소로 올리고 `docs/` 폴더를 GitHub Pages로 공개합니다.
올라가는 것은 앱 코드뿐이고 가계부 기록(개인 데이터)은 포함되지 않습니다.

- 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main` / `/docs`
- 주소: `https://<아이디>.github.io/gagyebu/`
- 갤럭시에서 **Chrome**으로 그 주소 열기 → 메뉴(⋮) → **앱 설치** (또는 **홈 화면에 추가**)
  - 삼성 인터넷: 메뉴 → **페이지 추가 → 홈 화면**

설치 후 처음 한 번 열면 오프라인에서도 동작합니다.

## 데이터 백업 (중요)
- 데이터는 그 폰의 Chrome(또는 설치한 앱) 저장소에만 있습니다. **앱 삭제, Chrome "사이트 데이터 삭제", 폰 교체 시 사라집니다.**
- 설정 → **백업 보내기**로 Google Drive 등에 주기적으로 저장하세요. 15건 이상 기록 후 30일간 백업이 없으면 첫 화면에 알림이 뜹니다.
- 새 폰에서는 앱 설치 후 설정 → **백업에서 복원**.

## 업데이트 배포
`docs/` 파일을 수정한 뒤 `docs/sw.js`의 `CACHE` 버전(예: `gagyebu-v1.0.1`)을 올리고 커밋·push 하세요 (1~2분 뒤 사이트에 반영).
폰에서는 앱을 한 번 열면 백그라운드에서 받아 두었다가 **다음 실행 때** 새 버전이 적용됩니다.

## PC에서 미리보기
```bash
node serve.js
```
브라우저에서 http://localhost:5180 (개발자 도구의 기기 모드에서 384×832로 보면 S22+ 크기)

## 파일 구조
```
docs/                 ← GitHub Pages로 공개되는 앱 (Pages가 /docs 폴더만 지원해서 이 이름)
  index.html          화면 뼈대
  style.css           디자인 (라이트/다크)
  app.js              앱 로직 전체
  sw.js               오프라인 캐시
  manifest.webmanifest 설치 정보 (이름, 아이콘, 바로가기)
  icons/              앱 아이콘 (tools/make-icons.js로 생성)
serve.js              로컬 테스트 서버
tools/make-icons.js   아이콘 생성기
```
